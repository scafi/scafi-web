Aggregate Programming in ScaFi

ScaFi is a comprehensive toolkit for Aggregate Programming, enabling decentralized coordination, collective intelligence, and complex self-organizing spatial patterns.

This interactive manual presents multiple real-time, side-by-side simulations directly connected to live compiled Scala scripts. You can interact with each node, modify values, or customize code in-place to explore how aggregate computations organize dynamically across physical space.

1. The Classic Gradient Field

A fundamental construct in Aggregate Programming is the Gradient Field (also called field evolution). A source node emits a signal (for example, sensor("sensor")), and all other nodes calculate their shortest metric distance to the closest source by sharing information dynamically with their physical neighbors.
